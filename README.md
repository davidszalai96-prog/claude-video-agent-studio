# claude-video-agent-studio

An agentic animation studio run by Claude Code on this PC: a Producer agent and 14 specialists that plan, generate (Krea 2 and MiniMax H3 in ComfyUI), review and edit (DaVinci Resolve or video-use) music videos and other short films, with every GPU run approved by the user.

- **Design (the spec):** `docs/studio-design.md` — the live version with diagrams is the Claude Doc "Agentic Animation Studio — Operating Design v1".
- **Measured notes:** `docs/notes/`
- **Skills:** `.claude/skills/` (ported to local Claude Code in Phase 1)
- **Start here:** `KICKOFF.md`

## Status

Starter kit only. Phase 1 (Foundation) builds the agents, rules, schemas, ComfyUI bridge, VRAM watchdog and guardrails.
